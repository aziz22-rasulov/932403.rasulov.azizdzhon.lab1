# Лабораторные работы №1–3. Сайт «О себе — путешественник»

- Секция «Навыки» — навыки, полезные в путешествиях.
- Секция «Проекты» — посещённые страны и личные путевые проекты.
- `<aside>` — любимый город/место.
- Цветовая гамма: бежево-оранжевая.

## Лабораторная работа №1. Основы HTML и структура веб-страницы

**Цель:** освоить базовую структуру HTML-документа, семантические теги, работу с текстом, списками, ссылками и изображениями.

### Что реализовано
- **Шапка (`<header>`):** имя студента — Расулов Азизджон, заголовок «О себе — путешественник и исследователь».
- **Основной контент (`<main>`):**
  - Секция «Навыки» — список навыков, полезных в путешествиях.
  - Секция «Посещённые страны» — нумерованный список `<ol>`: Узбекистан, Турция, Казахстан.
  - Секция «Связаться со мной» с формой обратной связи.
- **Боковая панель (`<aside>`):** любимый город — Томск, изображение с атрибутами `src`, `alt`, `width`, `height`.
- **Форма обратной связи:** поля «Имя» (`type="text"`), «Email» (`type="email"`), «Сообщение» (`<textarea>`), кнопка отправки; у всех полей — `name` и `placeholder`.
- **Подвал (`<footer>`):** копирайт и год — `&copy; 2026 Расулов Азизджон. Все права защищены.`

## Лабораторная работа №2. Базовые и продвинутые возможности CSS

**Цель:** научиться подключать стили, работать с селекторами, типографикой, цветами, отступами, позиционированием и псевдоклассами.

### Что реализовано
- **Внешний файл стилей** `style.css` — основной объём правил.
- **Внутренний блок `<style>`** в `<head>` — стили для секции «Проекты» (двухколоночная раскладка через `column-count`).
- **Inline-стиль** — кнопке отправки формы задан `font-size: 16px` прямо в HTML.
- **CSS-переменные в `:root`:** основной цвет — бежевый (`--cream`, `--paper`), акцент — оранжевый (`--rust`, `--rust-dark`), а также шрифты `--font-display` / `--font-body`.
- **Позиционирование:**
  - `position: static` — явно задан заголовку секции «Навыки».
  - `position: relative` — на боковой панели и элементах списков.
  - `position: absolute` — декоративный значок на боковой панели и нумерация стран.
- **Состояния элементов:** `:hover`, `:active`, `:focus` / `:focus-visible`, `:visited` — на ссылках навигации, полях формы и кнопке.
- **Липкая навигация (`position: sticky`)** — меню остаётся видимым при прокрутке; при наведении ссылка меняет цвет на оранжевый и под ней плавно появляется тонкая линия.
- **Контрастность текста** — не менее 4.5:1 (подобраны цвета `--muted`, `--rust-dark`, `--visited`).

## Лабораторная работа №3. Flexbox и CSS Grid, адаптивная вёрстка

**Цель:** освоить Flexbox для одномерных макетов и CSS Grid для двумерных, а также принципы адаптивной вёрстки.

### Что реализовано
- **Flexbox:**
  - Навигационное меню — горизонтальное, адаптивное (`flex-wrap: wrap`).
  - Секция «Навыки» переделана в карточки (`display: flex; flex-wrap: wrap`), внутри каждой карточки — `flex-direction: column`.
  - В каждой карточке — `<dl>` с парами `dt`/`dd` «Навык / Уровень» и прогресс-бар (`<div>` с шириной в процентах).
- **CSS Grid:**
  - Новая секция «Статистика прогресса» — три блока («Страны», «Города», «Фото»), сетка 3×1 на десктопе и 1×3 на мобильном.
- **Адаптивность:**
  - Карточки навыков — 4 колонки на десктопе, 2 на планшете, 1 на мобильном.
  - Grid-дашборд — 3 колонки, 1 колонка на мобильном.
  - Медиа-запросы для планшетов (`max-width: 900px`) и мобильных (`max-width: 600px`, `max-width: 780px`, `max-width: 500px`).
  - Горизонтальная прокрутка исключена (`overflow-x: hidden`, адаптивные изображения).
- **Контрастность** — не менее 4.5:1 для всех новых текстовых элементов; прогресс-бар — оранжевый на тёмно-сером фоне.
