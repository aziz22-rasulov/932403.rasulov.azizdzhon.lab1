# Лабораторная работа №1. Основы HTML и структура веб-страницы

**Цель:** освоить базовую структуру HTML-документа, семантические теги, работу с текстом, списками, ссылками и изображениями.

## Задание
Создать HTML-страницу «О себе», которая содержит следующие элементы:
- `<header>` — шапка с именем/фамилией студента и заголовком страницы.
- `<main>` — основной контент.
- Две секции `<section>`: «Навыки» (маркированный список) и «Проекты» (нумерованный список из 3–4 пунктов).
- `<aside>` — боковая панель с краткой информацией (например, «Любимые технологии»).
- `<footer>` — подвал с копирайтом и годом.
- Одно изображение (портрет/аватар) с атрибутами `src`, `alt`, `width`, `height`.
- Форма обратной связи: поля «Имя» (`type="text"`), «Email» (`type="email"`), «Сообщение» (`<textarea>`), кнопка отправки. У всех полей – атрибуты `name` и `placeholder`.

## Вариант 2. Тема «Путешественник»
- В секции «Навыки» — навыки, полезные в путешествиях.
- В «Проектах» — посещённые страны (3–4).
- В `<aside>` — любимый город/место.
- Цветовая гамма: бежево-оранжевая.

## Что реализовано
- **Шапка (`<header>`):** имя студента — Расулов Азизджон, заголовок «Путешественник».
- **Основной контент (`<main>`):**
  - Секция «Навыки» — маркированный список `<ul>`:
    - Знание иностранных языков
    - Умение ориентироваться по карте
    - Навыки выживания в дикой природе
  - Секция «Посещенные страны» — нумерованный список `<ol>`:
    - Узбекистан
    - Турция
    - Казахстан
  - Секция «Связаться со мной» с формой обратной связи.
- **Боковая панель (`<aside>`):** любимый город — Томск, добавлено изображение с атрибутами `src`, `alt`, `width`, `height`.
- **Форма обратной связи:**
  - Поле «Имя» (`type="text"`, `name="username"`, `placeholder="Введите ваше имя"`).
  - Поле «Email» (`type="email"`, `name="usermail"`, `placeholder="example@mail.ru"`).
  - Поле «Сообщение» (`<textarea>`, `name="usermessage"`, `placeholder="Напишите здесь свой текст..."`).
  - Кнопка отправки `<button type="submit">Отправить</button>`.
- **Подвал (`<footer>`):** копирайт и год — `&copy; 2024 Расулов Азизджон. Все права защищены.`
- **Стили:** бежево-оранжевая цветовая гамма, карточки с рамками и скруглёнными углами, центрирование, отступы.
